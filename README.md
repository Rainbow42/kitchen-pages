# На кухне

Меню, рецепты и календарь готовки для двух взрослых. Статическое приложение для GitHub Pages.

Публикация: Settings → Pages → Deploy from a branch → main → /(root).

Отметки и переносы хранятся в браузере. При переезде со старого адреса скачайте резервную копию в разделе «Как пользоваться» и восстановите её на новом сайте.
